About

About me

I’m Puspa Shahi, also known as BATIST, a cybersecurity student at KFA Business College in Kathmandu, Nepal.

My work focuses on offensive security, web application security, and API security. I enjoy understanding how systems are built, identifying weak assumptions, and evaluating how they behave under real attack conditions.

I’ve worked on security testing across web apps, APIs, Android app surfaces, and permissioned security testing workflows. I’m still learning, testing, and improving while helping teams identify and fix real issues before they become risks.

My interests include web exploitation, authorization flaws, IDOR/BOLA testing, reconnaissance, OSINT, and HTTP manipulation.

I use tools like Burp Suite, Caido, and Kali Linux to practice structured vulnerability analysis and improve my workflow as a security researcher.

I’ve helped identify issues such as IDOR exposure, open redirect behavior, exposed API keys in Android applications, and data leakage risks in permissioned testing environments.
